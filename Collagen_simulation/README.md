# Quantum-Inspired Collagen Lattice Simulation

A premium, interactive research showcase for simulating collagen fibrils and quantum-inspired repair optimization using QAOA algorithms.

## Overview

This project provides a cinematic, one-page web application to visualize and interact with a simulated tropocollagen lattice. It features:
- **Three.js 3D Background**: An organic, mathematically modeled cylindrical representation of collagen networks that reacts to mouse movement.
- **D3.js Simulation Engine**: A 2D network graph simulating tropocollagen molecules and cross-links with active physics.
- **Biophysical Dynamics**: Simulates localized stress, damage propagation, and network degradation.
- **Quantum Optimization (QAOA)**: Models the repair pathway using a parameterized quantum circuit-inspired process.
- **Live Telemetry & Dashboard**: Real-time evaluation of lattice coherence and node health via Chart.js.

## Tech Stack
- HTML5 / CSS3 (Vanilla, custom Design System)
- JavaScript (ES6 Modules)
- **Three.js** via CDN
- **D3.js** via CDN
- **Chart.js** via CDN

## Usage
Simply clone this repository and open `index.html` in your favorite web browser. No complicated build steps or backend servers are required—everything is completely client-side.

```bash
# Clone the repository
git clone https://github.com/Nickolas-Adrian-Papamichail/Collagen_simulation.git

# Enter the directory
cd Collagen_simulation

# Open the site
open index.html
```

## Structure
- `index.html`: Main structured entry point and layout.
- `styles.css`: Custom CSS with glassmorphism, responsive grid layouts, and custom scrollbars.
- `app.js`: Main logic for 3D rendering, D3 physics simulation, and data visualization.
